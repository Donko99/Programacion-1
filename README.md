# Programación 1
Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programación 1.
Los ejercicios están organizados por temas, y cada
programa se encuentra en su propia carpeta.

## Programas incluidos

### Figuras
Este programa permite al usuario seleccionar entre varias figuras usando simbolos y las dibuja.

### BlackJack
Este programa permite al usuario jugar al blackjack contra la computadora.
